# Quartz features

Features borrowed from Quartz, split by what the Jekyll site already does and what still needs building.

## Already on the site
- [x] Dark mode toggle (`#themeToggle`, remembered per visitor, `assets/js/site.js`)
- [x] Tag pages (`/tags/` and `/tags/<tag>/`, generated by `_plugins/sections.rb`)
- [x] RSS/Atom feeds (`/feed.xml` plus one per section, with `pretty-feed.xsl`)
- [x] Sitemap (`jekyll-sitemap`)
- [x] Open Graph, Twitter, and canonical metadata (`jekyll-seo-tag`)
- [x] Custom favicon (`favicon` in `_config.yml`)
- [x] Custom homepage (`index.html`)
- [x] Reading time (`_layouts/post.html`)
- [x] Last modified date ("updated …" from `updated` or the last git commit)
- [x] Search, titles only (`/navigate/`, client-side over `search.json`)
- [x] Footnote markup (kramdown handles `[^1]` natively; no custom styling yet)
- [x] Code block markup (kramdown + Rouge; no highlighting theme yet)
